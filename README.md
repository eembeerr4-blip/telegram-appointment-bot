# Beauty Salon Telegram Bot

Цей проект — Telegram-бот для салону краси. Бот привітає клієнта, показує інформацію про салон, допомагає записатися на послугу і надсилає заявку адміністратору.

## Що потрібно встановити

### Python
- Завантажити: https://www.python.org/downloads/
- Під час установки поставте прапорці:
  - Add Python to PATH
  - Install launcher for all users
- Перевірка:
  ```powershell
  py --version
  python --version
  ```

### VS Code
- Завантажити: https://code.visualstudio.com/
- Рекомендовано встановити розширення Python
- Перевірка:
  ```powershell
  code --version
  ```

### Git (необов'язково, але корисно)
- Завантажити: https://git-scm.com/
- Перевірка:
  ```powershell
  git --version
  ```

## Установка проекту

1. Відкрийте PowerShell у папці проекту.
2. Створіть віртуальне середовище:
   ```powershell
   python -m venv venv
   ```
3. Активуйте його:
   ```powershell
   .\venv\Scripts\activate
   ```
4. Встановіть залежності:
   ```powershell
   pip install -r requirements.txt
   ```

## Налаштування .env

Створіть файл `.env` на основі `.env.example` і заповніть дані.

### КУДА ВСТАВЛЯТЬ ТОКЕН БОТА

Токен потрібно вставити у файл `.env` у рядок `BOT_TOKEN`.

```env
BOT_TOKEN=ВСТАВИТИ_ТОКЕН_ВІД_BOTFATHER
ADMIN_ID=ВСТАВИТИ_ТЕЛЕГРАМ_ID_АДМІНА
SALON_ADDRESS=Адреса салону
SALON_PHONE=Телефон салону
```

### Де брати дані
- `BOT_TOKEN` — токен бота з BotFather
- `ADMIN_ID` — ваш Telegram ID, щоб заявка приходила адміністратору

## Встановлення бібліотек

```powershell
pip install -r requirements.txt
```

## Запуск бота

```powershell
python main.py
```

## Команди бота

- `/start` — головне меню
- `/help` — допомога
- `💎 Ціни` — показати ціни
- `📝 Записатися` — почати запис
- `📅 Мої записи` — переглянути записи
- `📍 Адреса` — показати адресу
- `📞 Зателефонувати` — показати номер телефону

## Як користуватися ботом

1. Клієнт запускає бота командою `/start`.
2. Він може подивитися ціни або адресу.
3. Натискає кнопку `📝 Записатися`.
4. Бот збирає:
   - ім'я;
   - номер телефону;
   - послугу;
   - дату та час.
5. Заявка зберігається у базі SQLite і надсилається адміністратору.

## База даних

Проект використовує SQLite. Файл бази:
- `database/salon.db`

## Як зупинити бота

Натисніть `Ctrl + C` у вікні PowerShell, де працює бот.

## Важливе для Windows

Якщо під час встановлення пакетів виникають помилки, найчастіше допомагає:
- Python 3.12
- віртуальне середовище `venv`
